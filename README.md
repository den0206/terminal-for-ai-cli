# AI Terminal

Terminal view in secondary sidebar for Cursor IDE / VS Code.

## Features

- Terminal interface in the secondary sidebar
- Multiple terminal sessions support
- Full xterm.js integration
- Theme aware

## Development

1. Install dependencies:
```bash
npm install
```

2. Compile TypeScript:
```bash
npm run compile
```

3. Press F5 to debug in VS Code Extension Development Host

## Requirements

- VS Code 1.85.0 or higher
- Node.js 18.x or higher
